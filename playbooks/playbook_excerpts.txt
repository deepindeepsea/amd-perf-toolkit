1.4.5 numactl
NUMA is a computer architecture design that separates memory into multiple domains that are directly attached to
a subset of processors. System architectures with NUMA tend to have better scalability, but efficient use of mem-
ory requires a conscious effort to affinity scheduling and allocating memory in the correct domain. Linux offers a
command-lineutilitycallednumactlthatprovidesausercontrolof
NUMA(Non-UniformMemoryAccess)policies,process–CPUaffinities,andprocess-memoryaffinities.Developers
andsystemadministratorsusenumactltoachievethisbetteraffiliation. (See: numactl).
Numactl enables processes or tasks to be restricted to specific CPU and memory areas and decreases traffic in the
system memory. This results in a reduction in cache misses, performance degradation, and latency. Additionally,
withtheusageofnumactl,moreefficientuseofCPU,memory,andI/Odevicescanbeobtained,andhelptoresolve
memorysharingissues.
